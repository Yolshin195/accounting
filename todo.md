# Домашняя бухгалтерия — требования к приложению

## 1. Неавторизованный пользователь
- Страница: **`landing.html`**
- Отображается **продающий лендинг**  
  (описание сервиса, преимущества, кнопка регистрации/входа).

## 2. Авторизованный пользователь

### 2.1 Главная страница (дашборд)
- Страница: **`dashboard.html`**
- Содержит:
  - Суммарные доходы и расходы
  - Баланс
  - Краткая статистика по категориям

### 2.2 Календарь
- Страница: **`calendar.html`**
- Просмотр периодов: **День / Неделя / Месяц / Год**
- Режим **Месяц**: в каждой ячейке дня показывать сумму доходов и расходов
- При клике на день — переход в детальный просмотр **этого дня**
- **Управление периодом**:
  - Кнопка **«Сегодня»** — возвращает к текущему дню/неделе/месяцу/году в зависимости от выбранного вида
  - Кнопки **«Предыдущий»** и **«Следующий»**, переключают соседний период относительно текущего вида:
    - День → предыдущий/следующий день
    - Неделя → предыдущая/следующая неделя
    - Месяц → предыдущий/следующий месяц
    - Год → предыдущий/следующий год
- Возможность **добавить транзакцию на выбранный день**

### 2.3 Планирование бюджета
- Страница: **`budget.html`**
- Содержит:
  - Настройку **планируемого дохода и расходов** по категориям
  - Отображение бюджета за месяц/год
  - Возможность корректировать план и видеть остаток/перерасход

### 2.4 Справочник шаблонных транзакций
- Страница: **`templates.html`**
- Возможности:
  - Создание **периодических транзакций** (например, ежемесячная зарплата, оплата квартиры)
  - Выбор периода повторения (ежедневно, еженедельно, ежемесячно, ежегодно)
  - Настройка автоматического создания или **напоминания с кнопкой «Создать»**
  - Возможность **редактировать существующие шаблоны**

### 2.5 Справочники
- Страница категории меню: **«Справочники»**, разворачивается при клике
- Страницы внутри категории:
  - **Счета** — `accounts.html` (например: наличные, карта, депозит)
  - **Валюты** — `currencies.html` (выбор основной валюты)
  - **Категории** — `categories.html`:
    - Категории **расходов**
    - Категории **доходов**

### 2.6 Настройки
- Страница: **`settings.html`**
- Отображается:
  - Имя пользователя
  - Кнопка **«Удалить все данные и аккаунт»**

## 3. Навигация
- Боковое меню слева с иконками для каждого пункта
- Меню **адаптируется под мобильные устройства**:
  - На мобильных — сворачиваемое «бургер»-меню / выезжающая панель (drawer)
  - Состояние меню (открыто/закрыто) не мешает доступу к основному контенту

## 4. Добавление транзакций
- Кнопка **добавления транзакции** в виде **круглой плавающей кнопки (FAB)**  
  — расположение: **нижний правый угол экрана**
- Кнопка **доступна на всех страницах**, если пользователь авторизован
- В календаре — транзакция добавляется **для выбранного дня** (если день выбран)

## 5. Адаптивность и технологии
- Весь сайт **адаптирован для работы на любом устройстве** (мобильные, планшеты, десктопы)
- Обязательно использовать **CSS-фреймворк** (например, **Bootstrap 5.3** или **Tailwind CSS**)
- Компоненты интерфейса (календарь, боковое меню, FAB, карточки дашборда) должны быть **резиновыми** и корректно перестраиваться на разных ширинах экрана

## 6. Формат ответа от LLM
- LLM должна возвращать **набор готовых HTML-страниц**:
  - `landing.html`, `dashboard.html`, `calendar.html`, `budget.html`, `templates.html`, `accounts.html`, `currencies.html`, `categories.html`, `settings.html`
- Каждая страница включает:
  - Подключение выбранного CSS-фреймворка
  - Боковое меню с иконками
  - Основной контент (в зависимости от страницы)
  - Плавающую кнопку добавления транзакции (FAB)

## 7. Локализация
- Все страницы должны поддерживать три языка:
  - **Русский**
  - **Английский**
  - **Тайский**
- Текстовые элементы интерфейса (кнопки, заголовки, меню, уведомления) должны переключаться между языками
